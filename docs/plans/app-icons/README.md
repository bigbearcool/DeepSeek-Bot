# App 图标候选（0.2.2）

三套预览都是圆角深色底板，方便对照桌面图标位。

| 方案 | 文件 | 说明 |
|------|------|------|
| **A · Character（默认进包）** | `A-character.png` | 深底 + 主题绿圆脸 + 两只眼睛，和通知小图标、助手形象同一语系，一眼能认出是 DS Bot |
| B · Bubble | `B-bubble.png` | 深底 + 主题蓝圆 + 白色对话气泡，更偏「聊天 App」 |
| C · Aurora | `C-aurora.png` | 深底 + 绿青蓝渐变圆脸，呼应「极光」配色，稍花一点 |

默认采用 **A**：干净、和现有绿点/角色语言一致，不会和系统蓝聊天图标撞车。
